# Patch Notes — 2026-05-18

## Fixes Applied

### 1. Login page — node click shifts card to the right
**File:** `app.py` ~line 9063
**Root cause:** `showTip()` set `tip.style.cssText` which overwrote the element's entire style,
stripping the `position:fixed` that was set in the HTML. The tip div reverted to `position:static`
and pushed into document flow, shifting the login card sideways.
**Fix:** Added `position:fixed;` as the first property in the `cssText` assignment.

### 2. Terms of Service page returning 500 error
**File:** `app.py` ~line 10322
**Root cause:** `_LEGAL_PAGE_CSS` was referenced in both `/terms` and `/privacy` page templates
but was never defined anywhere in the file — caused a `NameError` on every visit.
**Fix:** Defined `_LEGAL_PAGE_CSS` as a dark-theme CSS string immediately before the `/terms` route.
